## User Acceptance Checklist

1. New Game: accept/skip the folio; interrupt and resume in the journal, choose a
   different tracked quest, leave immediately, reload/Continue. No new quest,
   automatic journey entry, duplicate reward or automatic tutorial restart.
2. Use each quarter with keyboard/mouse and an actual phone. Check displayed
   targeting, wall/reach rejection, short-screen text, hand/tool contact, lid
   contents, bucket/rope, shutters, sit/stand, lamp state and ordinary services.
3. Use the notice board after private/public/retained reports and forge after
   all iron outcomes. Tor requires genuine discovery. Check a legacy obscured
   account: restore only the actual choice, with no second reward or false consent.
4. Land light/heavy dummy hits, dodge/sheath, cancel and hit with the practice bow
   in both cameras, and direct Oathfire at the target. Compare ammunition and
   equipment before/after practice. Block and parry separately in Wychwood.
5. Check real well/bell secrets and letter privacy; first arrival, road return,
   cemetery resolution, Assembly and full homecoming. Observe character access,
   sound, day/night composition and saved consequences. Measure reference-PC
   performance separately; neither compilation nor deployment establishes it.
