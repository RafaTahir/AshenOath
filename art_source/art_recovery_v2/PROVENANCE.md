# Review-only source provenance

The supplied 32-sheet pack remains the design authority. Its imagery is not projected onto a model or represented as a finished texture set.

Anwen reconstruction uses MakeHuman hm08 anatomical topology and the Caucasian female young/old morph assets, pinned at `a8bc2d54ff0ac92e78ff71431b1023eda42bf482`. The graphical assets are CC0, separately from MakeHuman's AGPL application code. Only mesh/target data and license statements are used; no MakeHuman application code is incorporated.

Upstream: https://github.com/makehumancommunity/makehuman/tree/a8bc2d54ff0ac92e78ff71431b1023eda42bf482

Asset license: https://github.com/makehumancommunity/makehuman/blob/a8bc2d54ff0ac92e78ff71431b1023eda42bf482/LICENSE.ASSETS.md

The existing Quaternius CC0 body rig, hand/boot geometry and shared animation library remain credited as retained work, not new anatomy. New head sculpt adjustments, clothing pattern meshes, seams, hair construction, review materials and production scripts are authored for this recovery. Sources are outside the game export. Review derivatives are not approved replacements and must not be deployed automatically.

The Blender MCP endpoint at localhost:9876 was unavailable at the start of this work. Blender 5.2.3 background execution was available and used directly. That is an execution fallback, not evidence of artistic approval.

The middle-age female skin, and unmodified braid/eye reference inputs, were selected from MakeHuman's official `makehuman_system_assets_cc0.zip`, downloaded from https://files2.makehumancommunity.org/asset_packs/makehuman_system_assets/makehuman_system_assets_cc0.zip . Its official inventory identifies these core assets as CC0: https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html . Only selected files are preserved under `upstream/makehuman/system_assets`; the full archive remains scratch under D: and is not exported or committed. Skin texture authorship is credited to the upstream MakeHuman asset, not claimed as original painting.
