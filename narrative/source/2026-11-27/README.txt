GAME ADAPTATION
The separate 11-page companion contains full story spoilers. It maps all
36 chapters to existing quest anchors, develops all 12 supporting arcs,
distinguishes new proposals from existing implementation, and preserves
dramatic treatments for all six game endings.

The book follows one literary continuity: Open Road, with Mira as the chosen
romance. Other player decisions remain available in the adaptation plan.
The chapter-map JSON is an authoring reference with PDF page numbers and
quest anchors; it is not a runtime data file to import without adaptation.
