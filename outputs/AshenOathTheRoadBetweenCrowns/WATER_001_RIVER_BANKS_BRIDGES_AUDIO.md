# WATER-001 — River, Banks, Bridges, and Audio

## Implementation

- Added sloped bank transitions that visually connect terrain to water.
- Added procedural depth, shallow-water, current, and shoreline foam cues.
- Added four stone bridge foundations without changing the walkable deck or ramps.
- Added a compact procedural spatial current loop aligned to each river.
- Preserved bridge-only crossing, barriers, recovery volumes, and save migration.

## Running

Run New Game and walk to the Greyfen bridge. Cross without jumping, inspect both banks, and listen near the channel. The same contract is used by the Wychwood crossing.
