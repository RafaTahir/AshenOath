# CHARACTER-REAL-001

## Result

Route-visible humans now use cohesive rigged Quaternius GLBs with mesh-native faces and complete bodies. Kael uses the Adventurer, Sister Anwen uses Animated Woman, villagers use male/female variants, Castle roles use Hooded Adventurer, and Long Road roles use Character Animated. The visibly segmented generated human prototypes were rejected and removed.

Wychwood enemies use three project-authored rigged variants with modeled eyes, jaws, teeth, complete limbs, distinct proportions, and existing combat animation hooks. Face cards, billboard faces, proxy limbs, and the generated face atlas are no longer used.

## Caveat

The result is cohesive stylized low-poly character art suitable for the Web build, not photoreal scanned humans. The full slice screenshot run currently reports an existing blacksmith safe-point drift after successfully capturing the primary route; this does not affect character loading or runtime progression.
