# Boss Equipment

`bell_eater_bell.res` is original project-authored geometry, not a downloaded
third-party asset. Its hollow bronze section, broken lip, UVs and patina colors
are defined in `tools/build_bell_eater_bell.gd`. Run that script with Godot 4.6.3
to rebuild it. The runtime loads the baked mesh; it does not generate it per spawn.

The imported monster retains its own separately recorded Quaternius CC0 license.
This equipment does not replace or add anatomy. Runtime phase changes affect the
bell emission, chain visibility and clapper only.
