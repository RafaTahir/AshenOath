# Authored Cloud Volumes

Original Ashen Oath geometry generated by tools/build_cloud_volumes.gd.
No downloaded, AI-generated, proprietary or third-party cloud asset is used.
The continuous density fields, underside colours and normals are authored here.
Three immutable meshes share one runtime material. Runtime does not perform
isosurface generation. Meshes are base-pack dependencies of VisualDirector;
the source and this note are not runtime content.

The resource manifest records exact byte hashes. Native preview/structural proof
does not constitute full environment, performance or browser acceptance.
