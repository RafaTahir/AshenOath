# WORLD-001 Zombie Kit Source Review

Verdict: rejected at source/art review. No runtime asset, role mapping, export
manifest or game source was changed. Formal Recovery-004 acceptance remains
27/37.

The [Quaternius Zombie Apocalypse Kit](https://quaternius.com/packs/zombieapocalypsekit.html)
is a genuine CC0, glTF-format pack from the same creator as the existing
character ecosystem. Only its four zombie glTFs, atlas, source license and
creator preview were downloaded to
`D:/Temp/AshenOath/quaternius_zombie_audition_20260929/` for inspection.
Each glTF has a skin and embedded buffer. Basic and Chubby include Crawl,
Death, HitReact, Idle, Punch, Run, Run_Attack and Walk; Arm has equivalent
combat/death clips; Ribcage has locomotion/hit/death but no attack clip. The
downloaded license states CC0 1.0, despite a stale pack-name heading.

The creator's full-model preview shows bright, short-limbed, comic zombie
bodies, including exposed tongue and oversized head/hand proportions. Even
with darker materials, this is not the grounded cursed-human Ghoulkin
silhouette required by the occupied Wychwood scene. Importing it would
repeat the prior cartoon-versus-dark-fantasy mismatch. The source is rejected
before a Godot mapping or costly export, not claimed as an in-game visual
pass. No source file from the pack entered the repository or Web payload.

Next: use a purpose-fitted authored humanoid assembly and complete combat
clips, or a genuinely appropriate licensed source. Do not map an asset only
because its skeleton or file format passes.
