# INV-001 — Preparation, Inventory, and Crafting

## Changes

- Added deterministic potion, bomb, oil, and trap ordering.
- Added recipe status with owned, required, and missing ingredient counts.
- Added one validated oil-application path and a compact preparation summary.
- Made legacy inventory loading preserve valid defaults and reject malformed item collections.
- Reworked the inventory panel into a preparation view with item purpose, recipe readiness, and contextual action verbs.

## Compatibility

Existing items, recipes, hotkeys, combat effects, quest hooks, and saves remain compatible. No combat values changed.

## Running

Start New Game, press `Tab`, and review Preparation. Craft buttons show ingredient readiness. Use `R` for Redroot, `F` for Ash Bomb, or use the panel to drink tonic, apply an oil, or set a trap.
